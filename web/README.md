# 前端源码

`index.html` 就是**完整的前端**——不是演示片段。
HTML、CSS、JavaScript 全在这一个文件里，四千多行，没有构建步骤、
没有依赖、没有 node_modules。改完刷新就生效。

## 直接打开就能看

文件里带了一份写死的演示数据。现在显式加 `?demo=1` 才进入演示模式；
不用后端，也不会向外发出任何请求。默认打开时会连接同源后端。

## 接你自己的后端

仓库现在包含 `backend/`：从仓库根目录运行 `python3 -m backend.app`，
再访问 `http://127.0.0.1:8765/`。演示 IIFE 不用删除；不带 `?demo=1`
时所有请求会照常发到同源的 `api/…`。

后端会在 `data/dwell.sqlite3` 保存聊天、窗口、留言、待办、日历、批注等数据；
日记墙、夜记、日报和书籍使用 `data/` 下便于人工维护的 JSON/Markdown 文件。

## 里面有什么

聊天主界面（流式、思维链、工具调用、代码块、图片、文件卡片、音乐卡片）、
顶上的弹窗、干活时那行动作词、液态玻璃那套皮、锁屏、
日记 / 待办 / 日历 / 日报 / 共读（分页、自动共享当前页、聊天/记事本双页小窗、
标题底边框/目录选中态记事本与图标新建、复用主聊天气泡、整书删除，以及 TXT、Markdown、JSON 上传）/ 健康 / 仓库 /
悄悄话各页、模型切换、搜索、容量、用量、窗口列表，以及 Claude / MCP 住客分开的
Recents 入口。

状态那一间没有包含在内。
